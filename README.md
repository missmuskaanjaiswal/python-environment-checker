Python Environment Checker

A Python Software Engineering project for the Rab Tech Academy Internship.

Overview

This tool checks the Python environment and reports useful system information.

Features

- Python version detection
- Disk space checking
- Environment variable inspection
- Developer tool availability checks
- Human-readable reports and JSON output
- Useful exit codes
- Unit testing

Technologies

- Python
- pytest
- TOML configuration

Project Status

Currently under development as part of the internship task.
